👁️ People Counter — YOLOv8 + IoU Tracking + Gradio UI

A fully functional real-time people counting system built using YOLOv8, IoU-based object tracking, and an interactive Gradio web interface.
This project detects and tracks unique people inside a video (CCTV / Mobile Footage) and generates a processed video with bounding boxes and unique IDs.

🚀 Features

✔ Detects people using YOLOv8 (pretrained)
✔ Assigns unique IDs using IoU-based tracking
✔ Keeps count of unique individuals
✔ Processes any uploaded video
✔ Outputs video with tracking overlays
✔ Clean Gradio Web UI for easy use
✔ No external server needed — runs locally
